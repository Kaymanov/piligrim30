# SPEC.md — Редизайн и SEO-перезапуск сайта «Правовой Пилигрим»

## 1. Общая информация

**Проект:** редизайн и разработка сайта юридического проекта «Правовой Пилигрим»  
**Текущий сайт:** https://piligrim30.ru/  
**Основная тематика:** банкротство физических лиц, списание долгов, юридические услуги  
**География продвижения:** Астрахань  
**Формат сайта:** премиальный продающий сайт + SEO-медиа внутри него  
**Контент:** новости, статьи и материалы пишет владелец сайта

**Интеграция заявок:** отправка на email

## 2. Цель проекта

Создать современный, быстрый, визуально привлекательный и SEO-ориентированный сайт юридического проекта «Правовой Пилигрим», который будет:

- привлекать клиентов из органического поиска по Астрахани;
- продавать юридические услуги без агрессивной рекламы;
- формировать доверие к компании и юристам;
- повышать конверсию посетителей в заявки;
- развивать экспертность через SEO-блог и новостной раздел;
- конкурировать в поисковой выдаче без зависимости от Яндекс Директа;
- позволять владельцу самостоятельно публиковать статьи, новости, кейсы и FAQ.

### Цветовая палитра

Рекомендуемая палитра:

```text
Основной цвет: глубокий синий / темно-графитовый
Акцент: золотой / песочный
Фон: белый / светло-серый
Дополнительный акцент: спокойный зеленый
Текст: темно-серый / почти черный
```

### Типографика

- крупные H1;
    
- четкая иерархия заголовков;
    
- комфортный размер текста;
    
- короткие абзацы;
    
- понятные списки;
    
- выделение важных смыслов.
    

### Визуальные принципы

- не использовать устаревшие юридические клише;
    
- избегать перегруженных баннеров;
    
- не использовать слишком много стоковых фото;
    
- добавить реальные фото офиса и команды;
    
- использовать SVG-иллюстрации и анимации;
    
- сделать интерфейс дорогим и аккуратным.

## 47. Риски

### SEO-риски

- невозможно гарантировать топ по всем запросам;
    
- конкуренты могут иметь сильные домены и возраст;
    
- без регулярного контента рост будет медленным;
    
- плохие поведенческие факторы могут тормозить продвижение.
    

### Технические риски

- тяжелые анимации могут ухудшить скорость;
    
- неправильная индексация может создать дубли;
    
- отсутствие редиректов может привести к потере позиций;
    
- некачественные изображения могут замедлить сайт.
    

### Контентные риски

- слишком общие статьи не дадут результата;
    
- юридически неточные формулировки могут снизить доверие;
    
- обещания без оговорок могут быть опасны;
    
- отсутствие кейсов снизит конверсию.

## 50. Финальное решение по стеку

Проект реализуется как headless-архитектура:

```text
Frontend: Next.js + TypeScript + Tailwind CSS + Framer Motion
Backend: Django + Django REST Framework
Database: PostgreSQL
Admin: Django Admin
Forms: Django API + email notifications
SEO: Next.js metadata + sitemap + RSS + JSON-LD
Content: управляется через Django Admin
```

Такой стек подходит для задачи, потому что позволяет одновременно получить:

- современный дизайн;
    
- высокую скорость;
    
- качественное SEO;
    
- удобное управление контентом;
    
- масштабируемость;
    
- возможность развивать сайт как SEO-медиа;
    
- контроль над каждой страницей и каждым SEO-элементом.
