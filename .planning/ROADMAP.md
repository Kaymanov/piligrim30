# ROADMAP.md — Правовой Пилигрим

## Milestone: v1.0 — Backend Phase 3

### Phase 3: Лиды, Защита форм и ИИ-Юрист

**Goal:** Реализовать email-уведомления о заявках, защиту форм (honeypot, валидация, дедупликация) и сервис ИИ-Юриста на базе Gemini 2.5 Flash с сохранением истории и fallback-механизмом.

**Requirements:** LEAD-01, LEAD-02, LEAD-03, LEAD-04, LEAD-05, LEAD-06, LEAD-07, AI-01, AI-02, AI-03, AI-04, AI-05, AI-06, AI-07, AI-08, AI-09

**Success Criteria:**

1. При создании заявки через API владелец получает email с полной информацией о лиде
2. Honeypot-поле отсекает ботов (заявка со заполненным honeypot отклоняется)
3. Невалидные данные (пустой телефон, отсутствие consent) возвращают 400 с описанием ошибок
4. Повторная отправка с того же телефона в течение 5 минут блокируется
5. Заявки, отправленные быстрее 3 секунд после загрузки формы, отклоняются (timestamp trap)
6. Заявки без подтверждения JS-взаимодействия (поведенческий флаг) отклоняются
7. CSRF-токен валидируется на всех form endpoints
8. `POST /api/v1/chat/` возвращает осмысленный ответ ИИ-юриста по теме банкротства
9. При недоступности Gemini API чат возвращает rule-based ответ (не 500)
10. Каждый ответ чата содержит юридический дисклеймер
11. История чата сохраняется в рамках сессии (до 20 сообщений)
12. Off-topic вопросы получают вежливый отказ с перенаправлением на тему банкротства

**Dependencies:** Phase 1-2 (completed)

**Status:** completed

### Phase 4: Frontend MVP

**Goal:** Реализовать полный frontend на Next.js 16 — дизайн-систему, главную страницу со всеми блоками, внутренние страницы (услуги, блог, кейсы, FAQ, контакты), чат-виджет ИИ-Юриста и техническое SEO.

**Requirements:** FE-01..FE-10

**Success Criteria:**

1. Дизайн-система соответствует DESIGN_SPEC.md (цвета, типографика, компоненты)
2. Header с glassmorphism, sticky, мобильное меню, dark mode toggle
3. Главная страница: все 10 секций (Hero, Problems, DebtTypes, Timeline, Quiz, Cases, Reviews, Blog, FAQ, CTA)
4. Квиз работает end-to-end (7 вопросов → отправка quiz-lead)
5. Страницы услуг рендерятся из API с SEO-полями
6. Блог: список, статья, категории
7. Chat widget подключен к /api/v1/chat/
8. sitemap.xml, robots.txt, RSS, JSON-LD генерируются
9. Mobile-first адаптивность (320px-1920px)
10. Lighthouse Performance > 85

**Dependencies:** Phase 3 (backend API)

**Status:** not_started
