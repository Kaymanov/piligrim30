# Plan 04-01: Дизайн-система, Layout и UI-компоненты

## Goal

Создать фундамент фронтенда: дизайн-систему (цвета, типографика, тема), общий layout (Header, Footer), переиспользуемые UI-компоненты (кнопки, карточки, формы, секции) и API-клиент. Всё по DESIGN_SPEC.md.

## Context

- Next.js 16 + React 19 + Tailwind 4 (уже настроены)
- Шрифт Inter с кириллицей (уже подключен)
- Proxy к backend через rewrites (уже работает)
- Нужно добавить: Framer Motion, дизайн-токены, компоненты

## Tasks

### 1. Установить зависимости

```bash
cd frontend && npm install framer-motion clsx
```

- `framer-motion` — анимации
- `clsx` — условные классы

### 3. API-клиент

**File:** `src/lib/api.ts`

Утилита для запросов к backend:

- `fetchAPI(endpoint, options)` — базовый fetch с error handling
- `getPages()`, `getServices()`, `getBlogPosts()`, `getCases()`, `getFAQ()`, `getReviews()`, `getSiteSettings()`
- `submitLead(data)`, `submitQuizLead(data)`, `submitCallback(data)`
- `sendChatMessage(message, quizContext?)`
- `getCSRFToken()`
- Автоматическое добавление CSRF-токена к POST-запросам
- Base URL через env или proxy (`/api/v1/`)

### 7. Форма заявки (LeadForm)

**File:** `src/components/forms/LeadForm.tsx`

- Поля: name, phone, message (optional), consent checkbox
- Honeypot field (hidden)
- Timestamp (\_ts) — записывается при mount
- Behavioral (\_hid) — записывается при первом interaction event
- CSRF token — получается при mount
- Валидация на клиенте (phone format, consent required)
- Состояния: idle, submitting, success, error
- Анимация success (Framer Motion)
