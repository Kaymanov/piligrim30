### 7. ИИ-Юрист (Chat Widget)

**Вариант размещения: A + B (зафиксировано)**

- **A:** Floating widget (правый нижний угол) — доступен на ВСЕХ страницах
- **B:** Секция-баннер после квиза "Остались вопросы? Спросите ИИ-Юриста" — открывает виджет с quiz_context

**Files:**

- `src/components/chat/ChatWidget.tsx` — основной виджет
- `src/components/chat/ChatButton.tsx` — floating кнопка
- `src/components/chat/ChatWindow.tsx` — окно чата
- `src/components/chat/ChatMessage.tsx` — сообщение (user/assistant)
- `src/components/chat/ChatInput.tsx` — поле ввода

Функциональность:

- Floating button в правом нижнем углу (fixed position)
- По клику раскрывается окно чата (анимация scale + fade)
- Приветственное сообщение при первом открытии
- Отправка сообщений → POST /api/v1/chat/
- Отображение истории (user messages справа, assistant слева)
- Typing indicator пока ждём ответ
- Дисклеймер внизу окна (постоянно видимый)
- Кнопка "Сбросить чат" → POST /api/v1/chat/reset/
- Передача quiz_context если пользователь прошёл квиз

Адаптивность:

- Mobile: полноэкранный чат (100vh, 100vw)
- Tablet+: окно 400x600px в правом нижнем углу
- Кнопка: 56px круг на mobile, 60px на desktop

## Verification Criteria

- [ ] Все страницы MVP рендерятся (услуги, блог, кейсы, отзывы, FAQ, контакты)
- [ ] Динамические маршруты работают ([slug])
- [ ] SEO metadata генерируется из API
- [ ] sitemap.xml доступен и содержит все URL
- [ ] robots.txt корректен
- [ ] JSON-LD валиден (проверка через Google Rich Results Test)
- [ ] Chat widget работает: отправка сообщений, получение ответов, история
- [ ] Chat widget адаптивен: fullscreen на mobile, popup на desktop
- [ ] 404 страница отображается
- [ ] Адаптивность на всех страницах:
  - Mobile (320-767px): одноколоночный layout, крупные touch targets
  - Tablet (768-1023px): двухколоночные grids
  - Laptop (1024-1279px): полный layout
  - Desktop (1280-1920px): max-width контейнер, комфортная ширина чтения
