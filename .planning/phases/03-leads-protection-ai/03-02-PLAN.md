# Plan 03-02: ИИ-Юрист (Chat Service)

## Goal

Создать Django-приложение `chat` с endpoint `/api/v1/chat/` для ИИ-юриста на базе Gemini 2.5 Flash. Чат отвечает на вопросы по банкротству/долгам, сохраняет историю в сессии, имеет fallback при недоступности API и добавляет юридический дисклеймер к каждому ответу.

## Context

**Текущее состояние:**

- `GEMINI_API_KEY` уже в `.env.example`
- Нет приложения `chat` — создаём с нуля
- Redis доступен для кэширования/сессий
- Django sessions middleware уже в MIDDLEWARE

**Архитектура:**

```
Frontend → POST /api/v1/chat/ {message, quiz_context?}
         → Django View
         → GeminiService.generate(message, history, context)
         → Response {reply, disclaimer}
```

- Короткие сообщения (приветствия, "да", "нет") → on-topic (контекстные)

### 8. Сериализатор и View

**File:** `backend/apps/chat/serializers.py`

```python
class ChatMessageSerializer(serializers.Serializer):
    message = serializers.CharField(max_length=2000)
    quiz_context = serializers.DictField(required=False, allow_null=True)

class ChatResponseSerializer(serializers.Serializer):
    reply = serializers.CharField()
    disclaimer = serializers.CharField()
    is_fallback = serializers.BooleanField()
```

**File:** `backend/apps/chat/views.py`

```python
class ChatView(APIView):
    throttle_classes = [ChatRateThrottle]  # 10/min per session

    def post(self, request):
        serializer = ChatMessageSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)

        message = serializer.validated_data['message']
        quiz_context = serializer.validated_data.get('quiz_context')

        # Get/create session history
        history = request.session.get('chat_history', [])

        # Check off-topic
        if not is_on_topic(message) and len(history) == 0:
            return Response({
                'reply': OFF_TOPIC_RESPONSE,
                'disclaimer': LEGAL_DISCLAIMER,
                'is_fallback': True
            })

        # Try Gemini
        service = GeminiChatService()
        try:
            if service.is_available():
                reply = service.generate_response(message, history, quiz_context)
                is_fallback = False
            else:
                raise GeminiUnavailableError()
        except GeminiUnavailableError:
            reply = get_fallback_response(message)
            is_fallback = True

        # Update history (max 20 messages)
        history.append({'role': 'user', 'content': message})
        history.append({'role': 'assistant', 'content': reply})
        if len(history) > 40:  # 20 pairs
            history = history[-40:]
        request.session['chat_history'] = history

        return Response({
            'reply': reply,
            'disclaimer': LEGAL_DISCLAIMER,
            'is_fallback': is_fallback
        })
```

## Verification Criteria

- [ ] POST /api/v1/chat/ с on-topic сообщением → 200 с reply + disclaimer
- [ ] POST /api/v1/chat/ с off-topic сообщением (первое) → 200 с вежливым отказом
- [ ] При недоступности Gemini API → 200 с fallback ответом (не 500)
- [ ] Каждый ответ содержит `disclaimer` поле
- [ ] История сохраняется в сессии (повторный запрос учитывает контекст)
- [ ] После 20 пар сообщений старые обрезаются
- [ ] 11-й запрос за минуту → 429 Too Many Requests
- [ ] quiz_context передаётся в промпт и влияет на ответ

## Dependencies

- `google-genai` package
- Redis (для сессий)
- GEMINI_API_KEY в .env

## Risks

- Gemini API может быть медленным → timeout 10 sec + fallback
- Gemini может генерировать некорректные юридические советы → системный промпт ограничивает + дисклеймер
- Session storage в Redis может быть потерян → не критично, история начнётся заново
