# REQUIREMENTS.md — Правовой Пилигрим (Phase 3)

## v1 Requirements

### Лиды и Защита форм

- [ ] **LEAD-01**: При создании заявки (Lead) отправляется email-уведомление владельцу сайта с полной информацией (имя, телефон, сообщение, сумма долга, UTM, страница, дата)
- [ ] **LEAD-02**: Формы защищены honeypot-полем (скрытое поле, заполнение которого = спам)
- [ ] **LEAD-03**: Серверная валидация всех полей формы (phone format, required fields, consent)
- [ ] **LEAD-04**: Защита от повторной отправки (дедупликация по phone + 5 min window)
- [ ] **LEAD-05**: Временная ловушка — отклонение заявок, отправленных быстрее 3 секунд после загрузки формы (timestamp validation)
- [ ] **LEAD-06**: Поведенческая ловушка — проверка наличия JS-взаимодействия (mouse/touch/keyboard event flag)
- [ ] **LEAD-07**: CSRF-токен на всех form endpoints (Django CSRF middleware + передача токена фронтенду)

### ИИ-Юрист (Chat Service)

- [ ] **AI-01**: Endpoint `POST /api/v1/chat/` принимает сообщение пользователя и возвращает ответ ИИ-юриста
- [ ] **AI-02**: Интеграция с Gemini 2.5 Flash API для генерации ответов
- [ ] **AI-03**: Системный промпт задает роль юриста-консультанта по банкротству в Астрахани
- [ ] **AI-04**: Контекст из квиза (сумма долга, наличие имущества, просрочки) передается в промпт для персонализации ответа
- [ ] **AI-05**: История чата сохраняется в сессии (session-based, до 20 сообщений)
- [ ] **AI-06**: Fallback rule-based механизм при недоступности Gemini API (заготовленные ответы по ключевым темам)
- [ ] **AI-07**: Каждый ответ ИИ содержит юридический дисклеймер: «Данная информация носит ознакомительный характер и не является юридической консультацией»
- [ ] **AI-08**: Rate limiting на chat endpoint (10 req/min per session)
- [ ] **AI-09**: Фильтрация off-topic вопросов (ИИ отвечает только на юридические вопросы по банкротству/долгам)

## v2 Requirements (Deferred)

- Telegram-уведомления о заявках
- Яндекс SmartCaptcha / Cloudflare Turnstile
- Интеграция с CRM
- Расширенный квиз с ветвлением
- Streaming ответов ИИ (SSE)
- Аналитика использования чата

## Out of Scope

- Frontend реализация — отдельная фаза
- Голосовой ввод в чат — не планируется
- Оплата через чат — не планируется
- Автоматическое создание заявки из чата — v2
